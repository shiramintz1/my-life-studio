# My Life Studio

אתר אישי בעברית לניהול משימות, תכנון שבועי, אימוני גיטרה, פרויקטים באולפן ורעיונות יצירתיים.

## הפעלה
פתחו את `index.html` בדפדפן או פרסמו את המאגר דרך Vercel.

## שמירת נתונים
המידע נשמר בדפדפן המקומי באמצעות `localStorage`. הוא אינו מסתנכרן אוטומטית בין מכשירים או דפדפנים. השתמשו באפשרות הגיבוי באתר כדי לשמור עותק.
