# My Life Studio

אתר אישי בעברית לניהול משימות, לימודי גיטרה, פרויקטים באולפן, מחברת יצירה ומטרות שבועיות.

## מה עובד בגרסה הזאת?
- מסך בית עם סיכום משימות, פרויקטים, רעיונות ואימוני גיטרה.
- הוספה וסימון של משימות.
- יומן אימוני גיטרה ונושאים לחיזוק.
- מעקב אחר פרויקטים באולפן ושינוי שלב הפרויקט.
- מחברת לכתיבה, רעיונות לשירים, ציור והשראה.
- מטרות שבועיות ותכנון פעילויות לפי ימים.
- ייצוא וייבוא גיבוי JSON.
- עיצוב רספונסיבי למחשב ולנייד.

## הרצת האתר במחשב
פתחו את `index.html` בדפדפן. אין צורך בהתקנה.

## פרסום ב-GitHub וב-Vercel
1. היכנסו ל-GitHub וצרו repository חדש בשם `my-life-studio`.
2. העלו לתוכו את הקובץ `index.html` ואת `README.md` (או העלו את תוכן קובץ ה-ZIP).
3. היכנסו ל-Vercel ובחרו Add New → Project.
4. חברו את חשבון GitHub, בחרו את `my-life-studio` ולחצו Deploy.
5. מאחר שזה אתר סטטי ללא build step, בדרך כלל אפשר להשאיר את הגדרות הבנייה כברירת מחדל. אם Vercel מבקש הגדרות, בחרו Other/Static וללא Build Command, עם תיקיית פלט `.`.
6. לאחר הפרסום תקבלו כתובת `*.vercel.app`. כל push חדש ל-GitHub יפעיל פריסה מחדש.

## חשוב לדעת
הנתונים נשמרים ב-localStorage של הדפדפן שבו משתמשים באתר. הם לא מסתנכרנים אוטומטית בין מכשירים או דפדפנים, ואין כאן עדיין חשבונות משתמשים או מסד נתונים. הורידו גיבוי JSON מדי פעם. אל תשמרו באתר סיסמאות או מידע רגיש.

## מבנה
- `index.html` — האתר כולו (HTML, CSS ו-JavaScript).
- `README.md` — הוראות שימוש ופרסום.
